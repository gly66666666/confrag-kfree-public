# ConfRAG k-free 文档分组实验

当多篇检索文档对同一个问题给出不同答案时，模型能否识别有哪些观点，并把支持同一观点的文档归到一起？本项目用 ConfRAG 的开发样本评估这两项能力，分别测试给定参考组数和由模型自行判断组数的条件。

## 150 题基线

三种模型在相同的 150 道题上各运行两种条件，共 900 个任务。每对任务使用相同的文档和顺序。评分使用最终分组表。12 个接口错误单列，其余 888 个任务可评分。B³ F1 按题计算后取平均，整题全对要求文档分组与参考划分完全一致。

| 模型 | 组数已知 B³ F1 | 组数未知 B³ F1 | 组数已知整题全对 | 组数未知整题全对 |
| --- | ---: | ---: | ---: | ---: |
| DeepSeek V4.1 Flash | 0.8083 | 0.7842 | 46/150 | 30/150 |
| GLM-5.3-Flash | 0.7867 | 0.7828 | 40/146 | 28/145 |
| Qwen3.8-Flash | 0.8066 | 0.7564 | 41/148 | 20/149 |

已知组数条件下，有 401 份输出给出了正确的组数，其中 **274 份仍把文档分错组**。逐题配对重采样 10,000 次所得的 B³ F1 差值（已知减未知）分别为 +0.0241、+0.0021 和 +0.0488。对应的 95% 区间为 [0.0059, 0.0424]、[−0.0185, 0.0224] 和 [0.0314, 0.0674]，未作多重比较校正。

## 30 题方法对照

在相同的 30 道未知组数开发题上比较直接分组、先提取证据再分组、分组后额外复核。每题每个设置各请求一次，共 270 个任务。下列分数使用各模型在同一方法下的可评分结果。

| 模型 | 直接分组 | 证据后分组 | 证据后分组并复核 | 各方法可评分数 |
| --- | ---: | ---: | ---: | ---: |
| DeepSeek V4.1 Flash | 0.7786 | 0.7684 | 0.7509 | 30/30 |
| GLM-5.3-Flash | 0.7573 | 0.7708 | 0.8004 | 27/30 |
| Qwen3.8-Flash | 0.7391 | 0.7785 | 0.7948 | 30/30 |

证据提取加复核在这批题上提高了 GLM 和 Qwen 的平均分，DeepSeek 的平均分下降。三个模型的平均输出 token 数均有所增加。该对照用于探索模型差异。两轮实验均使用开发题，报告的是给定检索文档后的分组能力。

## 运行评分示例

使用 Node.js，无需安装依赖或调用模型 API。

```bash
node score.mjs example.json
```

示例使用合成文档 ID，展示组数相同且文档归组不同的情况。命令输出组数是否正确、分组是否完全一致，以及 B³ Precision、Recall 和 F1。可将输入中的 `reference` 和 `prediction` 换成同一批文档的两种划分，组名和组内顺序不参与比较。

此公开版提供汇总结果和评分示例。原始基准的题目、文档及获取方式见 [ConfRAG 数据卡](https://huggingface.co/datasets/OracleY/ConfRAG) 和 [原作者仓库](https://github.com/XaiverYuan/ConfRAG)。
